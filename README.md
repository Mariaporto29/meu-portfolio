# Portfólio de Maria Porto

Portfólio pessoal criado com React e Vite para apresentar minha atuação em PCP/TI e meus estudos em análise de dados, automação e ETL.

## O que você encontra aqui

- Apresentação profissional e competências em SQL, MySQL, Python, Pandas, Power BI e ETL.
- Estudo de análise de acidentes em desenvolvimento. A fonte dos dados e os resultados ainda não estão publicados.
- Projeto complementar de jogo em JavaScript: [jogo_basico](https://github.com/Mariaporto29/jogo_basico).
- Contato pelo [GitHub](https://github.com/Mariaporto29).

## Executar localmente

Requer Node.js e npm.

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```
